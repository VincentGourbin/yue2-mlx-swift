### 2.1 Vocabulaire et protocole de prompt (`protocol.py`)

| Constante | Valeur | Rôle |
|---|---|---|
| `EOD` | 151643 | `<\|endoftext\|>` — premier token de tout préfixe ; borne supérieure (exclue) des tokens texte |
| `ABC_START` / `ABC_END` | 151847 / 151848 | `<abc>` / `</abc>` |
| `MUSIC_START` / `MUSIC_END` | 151851 / 151852 | début / fin des tokens sémantiques |
| `CODEC_OFFSET` / `CODEC_SIZE` | 151853 / 32768 | token sémantique `c` ∈ [0, 32768) ↔ id `CODEC_OFFSET + c` ; **1 token = 1 frame latente = 40 ms (25 Hz)** |
| `LATENT_START` / `LATENT_END` / `LATENT_PAD` | 184621 / 184622 / 184623 | ids réservés (positions NAR) — jamais échantillonnés |
| `VOCAB_SIZE` | 184704 | taille de `embed_tokens` et `lm_head` |
| `CONTEXT` | 24576 | `max_position_embeddings` — jamais dépassé, jamais tronqué implicitement |

Instructions natives (chaîne exacte, dans cet ordre de clés) :
- `off` : `Generate music with codec tokens from the given conditions.`
- `melody` : `Generate a melody-only ABC transcription without chord symbols, then generate music with codec tokens from the given conditions.`
- `full` : `Generate a chord-annotated ABC transcription, then generate music with codec tokens from the given conditions.`

Texte de requête : `"{INSTRUCTION}\n[Tags]\n{style}\n[Lyrics]\n{lyrics}\n"` (un `\n` final). `base = [EOD] + encode(texte)`.

| Préfixe | Construction |
|---|---|
| Phase ABC (cot ≠ off, pas d'ABC fourni) | `base + [ABC_START]` |
| Phase sémantique (cot ≠ off) | `base + [ABC_START] + abc_ids + [ABC_END, MUSIC_START]` — `abc_ids` = ids générés en phase ABC **ou** `encode(abc)` si fourni (tous < EOD) |
| Phase sémantique (cot = off) | `base + [ABC_START, ABC_END, MUSIC_START]` |
| Négatif CFG (cot ≠ off) | `[EOD] + encode(INSTRUCTION) + [ABC_START] + abc_ids + [ABC_END, MUSIC_START]` |
| Négatif CFG (cot = off) | `[EOD] + encode(INSTRUCTION) + [MUSIC_START]` |

`guidance` (cfg_scale effectif) : valeur fournie, sinon **1.0** pour full/melody et **1.01** pour off. CFG actif ssi `guidance != 1` (donc par défaut : uniquement en mode off, avec deux branches).

`SongRequest` : `style`, `lyrics`, `cot ∈ {off, melody, full}` (défaut full), `seed` (défaut 831001, entier [0, 2^63)), `abc` optionnel (interdit avec off, non vide), `cfg_scale` optionnel ∈ [0, 20], `id` (nom de fichier sûr). Exemple canonique : `examples/song.json` (style piano pop anglais, seed 831001).
