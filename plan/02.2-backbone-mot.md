### 2.2 Backbone MoT (`modeling_yue2.py`)

Hyperparamètres (`config.json`) : `hidden_size 2048`, `num_hidden_layers 28`, `num_attention_heads 16`, `num_key_value_heads 8` (GQA ×2), `head_dim 128`, `intermediate_size 6144`, `vocab_size 184704`, `rms_norm_eps 1e-6`, `rope_theta 1e6`, `max_position_embeddings 24576`, `latent_dim 64`, `max_latent_frames 24576`, `timestep_shift 1.0`, `tie_word_embeddings false`, dtype **bf16**.

Chaque `DecoderLayer` contient **deux voies complètes** (c'est le « Mixture-of-Transformers ») :

```
voie AR  : input_layernorm → self_attn(q,k,v,o + q_norm,k_norm) → +res → post_attention_layernorm → mlp(gate,up,down) → +res
voie NAR : nar_input_layernorm → nar_self_attn(idem) → +res → nar_pre_mlp_layernorm → nar_mlp → +res
```

- **Attention** : Qwen3-style. `q = q_norm(q_proj(x).view(B,T,16,128))`, `k = k_norm(k_proj(x).view(B,T,8,128))` (RMSNorm par tête, **avant** RoPE), puis RoPE **non entrelacé** (« rotate_half » : moitiés `[:64]` / `[64:]`) ⇒ `MLXFast.RoPE(traditional: false, base: 1e6, dimensions: 128)`. Échelle `1/sqrt(128)`. Pas de biais. GQA natif dans `MLXFast.scaledDotProductAttention`.
- **RMSNorm** : `x * rsqrt(mean(x.float()^2) + eps).to(x.dtype) * weight` — variance en fp32, résultat bf16. ⇒ `MLXFast.rmsNorm(x, weight: w, eps: 1e-6)` (calcul interne fp32, identique).
- **MLP** : SwiGLU `down(silu(gate(x)) * up(x))`.
- **Sortie** : `norm` (RMSNorm final) → `lm_head` (184704 × 2048, non lié).
- **Modules auxiliaires NAR** (hors couches) : `vae2llm` Linear(64 → 2048, **avec biais**), `llm2vae` Linear(2048 → 64, **avec biais**), `time_embedder` (sinus 256-d → Linear(256, 2048) → SiLU → Linear(2048, 2048), avec biais), `latent_pos_embed.pe` (**buffer bf16 [24576, 2048] présent dans le checkpoint** : on le charge tel quel, on ne le recalcule pas).
- En mode AR (génération), seule la voie AR est exécutée. En mode NAR (`CachedNAR`), la voie AR n'est exécutée que pour le prefill du préfixe (dont on garde K/V par couche), puis seule la voie NAR tourne pendant l'ODE.
