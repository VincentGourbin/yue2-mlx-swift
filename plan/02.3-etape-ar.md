### 2.3 Étape AR — phases ABC et sémantique (`sampling.py`)

Boucle par phase : prefill du préfixe (cache KV statique dimensionné `len(prefix) + max_tokens`), puis décodage token par token. Chaîne de traitement des logits, **dans cet ordre exact** (`distribution()`), sur des scores **fp32** (sauf `legacy_off` = cot off : reste en bf16) :

1. **Masque des tokens autorisés** : phase ABC → ids `[0, EOD)` + `ABC_END` ; phase sémantique → ids `[CODEC_OFFSET, CODEC_OFFSET+32768)` + `MUSIC_END`. Tout le reste = `-inf`.
2. **`min_tokens`** : si `step < min_tokens`, le token de fin (`ABC_END` ou `MUSIC_END`) = `-inf`.
3. **Pénalité de répétition fenêtrée** (`window_penalty`) sur les `penalty_window` derniers tokens **générés** (pas le préfixe) : `freq[id]` = nombre d'occurrences dans la fenêtre ; `alpha = penalty ** freq` ; `logit < 0 → logit * alpha`, sinon `logit / alpha`. (Un token absent de la fenêtre a alpha = 1.)
4. Si `temperature == 0` → `argmax` (fin). Sinon `scores /= temperature`.
5. **top-k** : seuil = k-ième plus grande valeur ; tout score `< seuil` → `-inf` (les égalités sont conservées).
6. **top-p** : tri décroissant, `p = softmax`, retirer les positions où `cumsum(p) - p > top_p`, **mais toujours conserver la première** (les **3 premières** si `legacy_off`) ; renvoyer dans l'ordre original.
7. `softmax` puis tirage multinomial (`MLXRandom.categorical`).

| Phase | temperature | top_p | top_k | repetition_penalty | penalty_window | min_tokens | max_tokens |
|---|---|---|---|---|---|---|---|
| ABC | 0.7 | 0.9 | 30 | 1.005 | 100 | 32 | 4096 |
| sémantique | 1.0 | 0.95 | 100 | 1.2 | 50 | 200 | 9000 |

(`yue2_generation_config.json` ; `ode_steps 32`, `ode_method midpoint`, `context 24576`.)

- Le token de fin est **consommé** (il termine la boucle, n'est pas ajouté à `history`). Résultat : `history` (tokens de contenu), `truncated = !eos`.
- **CFG** (si `guidance != 1`) : deux caches (positif, négatif), `logits = uncond + scale * (cond - uncond)` **en bf16 avant** le passage en fp32 de l'étape 1. Le même token échantillonné alimente les deux caches.
- Contrainte : `len(prefix) + max_tokens ≤ 24576`, sinon erreur (pas de troncature).
- Tokens sémantiques renvoyés au pipeline : `id - CODEC_OFFSET` (∈ [0, 32768)).
- Optimisation **exacte** autorisée (§7) : ne calculer `lm_head` que sur les lignes autorisées de la phase (ABC : 151 644 lignes ; sémantique : 32 769 lignes) — la softmax restreinte est identique puisque le reste est `-inf`.
