### 2.5 VAE — décodeur Oobleck (`modeling_vae.py`, dérivé de stable-audio-tools)

`config.json` (identique pour standard et legacy) : `channels 64`, `c_mults [1,2,4,8,16,32]`, `strides [2,2,4,4,5,6]` (produit = 1920 = `downsampling_ratio`), `latent_dim 64`, `out_channels 2`, `use_snake true`, `snake_type vanilla`, `final_tanh false`, `use_filter false`, `sample_rate 48000`, `decode_core_frames 1024`, `decode_halo_frames 16`. **fp32 obligatoire** (README : « Keep the VAE in FP32 »).

Topologie du décodeur (`decoder.layers`, `nn.Sequential`, indices = clés du checkpoint) :

| Index | Module | Détail |
|---|---|---|
| 0 | `WNConv1d(64 → 2048, k=7, p=3)` | weight-norm |
| 1..6 | `DecoderBlock(in → out, stride)` : (2048→1024, s6), (1024→512, s5), (512→256, s4), (256→128, s4), (128→64, s2), (64→64, s2) | chaque bloc = `SnakeBeta(in)` → `WNConvTranspose1d(in→out, k=2s, stride=s, padding=ceil(s/2))` → 3 × `ResidualUnit(out, dilation 1, 3, 9)` |
| 7 | `SnakeBeta(64)` | |
| 8 | `WNConv1d(64 → 2, k=7, p=3, **bias=False**)` | |
| 9 | `Identity` (final_tanh false) | pas de tanh, pas de clip dans le modèle (le pipeline clampe [-1, 1] à l'export) |

`DecoderBlock.layers` = Sequential `[0: SnakeBeta, 1: ConvTranspose, 2/3/4: ResidualUnit]`. `ResidualUnit.layers` = Sequential `[0: SnakeBeta, 1: WNConv1d(k=7, dilation d, padding 3d), 2: SnakeBeta, 3: WNConv1d(k=1)]`, sortie `x + layers(x)`.

- **SnakeBeta** (alpha/beta **log-scale**, un paramètre par canal) : `a = exp(alpha)`, `b = exp(beta)`, `y = x + (1/(b + 1e-9)) · sin(x·a)²`. Identique à `ltx BigVGANVocoder.swift` `SnakeBeta` (à copier).
- **weight_norm** (stocké `weight_g`, `weight_v`, dim=0 PyTorch) : `w = g · v / ‖v‖` où la norme est prise sur **toutes les dimensions sauf 0**. Conv1d : `v [out, in, k]`, `g [out, 1, 1]`. ConvTranspose1d : `v [in, out, k]`, `g [in, 1, 1]` (la norme est par canal **d'entrée**). Fusion **au chargement**, **avant** la conversion de layout (pattern `h3 VAEWeightLoader.swift`).
- **Layouts MLX (NLC)** : Conv1d torch `[out, in, k]` → MLX `[out, k, in]` (`transposed(0, 2, 1)`) ; ConvTranspose1d torch `[in, out, k]` → MLX `[out, k, in]` (`transposed(1, 2, 0)`). Formule de sortie MLX `convTransposed1d` = `(L-1)·s - 2p + d(k-1) + 1 + outputPadding` — **identique à PyTorch** (vérifié dans `mlx/ops.cpp`, `conv_transpose_general`), `outputPadding = 0`.
- **Longueur naturelle** : `1920·T - 64` échantillons pour T frames (à asserter).
- **Décodage tuilé** (`decode_tiled`) : cœur `core = 1024` frames (512 si budget ≤ 12 Go), halo `16` frames de chaque côté ; pour chaque tuile `[start, end)` : `left = max(0, start - 16)`, `right = min(T, end + 16)`, `tile = decode(z[left:right])`, `crop = tile[(start-left)·1920 : (start-left)·1920 + (out_end - out_start)]` avec `out_start = start·1920`, `out_end = min(end·1920, 1920·T - 64)`. **Pas de crossfade** : le halo suffit à reproduire exactement le décodage complet (test « tiled == full » de la référence, tolérance 3e-5 rel / 3e-6 abs).
- Entrée du pipeline : latents `[T, 64]` fp32 → `[1, 64, T]` torch, soit `[1, T, 64]` en NLC MLX (aucune transposition nécessaire depuis la sortie NAR).
- Export : `audio[0].T.clamp(-1, 1)` → WAV (référence : FLOAT 32-bit ou FLAC PCM_24). Le port écrit **WAV float32** (fidélité) et **WAV int16** (écoute) ; pas de FLAC en v1.
