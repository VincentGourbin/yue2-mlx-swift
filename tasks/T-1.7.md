## Fichiers à créer
- `Sources/YuE2Core/Loading/WeightLoader.swift` : `public enum WeightLoader { static func load(url: URL, filter: (String) -> String?) throws -> [String: MLXArray]` (via `loadArrays(url:)`) ; `static func apply(_ weights: [String: MLXArray], to module: Module, component: String) throws` — calcule `expected = module.parameters().flattened()` keys, `missing = expected − weights`, `unexpected = weights − expected` ; si l'un est non vide : `throw YuE2Error.weightMismatch("<component>: missing=[…] unexpected=[…]")` (limiter l'affichage à 10 noms) ; sinon `module.update(parameters: ModuleParameters.unflattened(weights))` puis `eval` **tenseur par tenseur** dans une boucle. }`
- `Sources/YuE2Core/Loading/VAEWeightLoader.swift` : `static func mergeWeightNorm(g: MLXArray, v: MLXArray) -> MLXArray` (`v * g / sqrt(sum(v², axes: toutes sauf 0, keepDims))`), `static func conv1dToMLX(_ w) -> w.transposed(0, 2, 1)`, `static func convTransposed1dToMLX(_ w) -> w.transposed(1, 2, 0)` ; `static func loadDecoderWeights(directory: URL) throws -> [String: MLXArray]` : ne garde que `decoder.*`, fusionne chaque paire `<p>.weight_g` + `<p>.weight_v` → `<p>.weight`, décide transposée vs conv par la forme attendue (la transposée est la clé `layers.{1..6}.layers.1`), convertit les layouts, `asType(.float32)`, `eval` par tenseur.
