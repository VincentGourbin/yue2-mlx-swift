# T-6.9 — Intégration du décodeur VAE Core AI dans l'app (si E3 est go)

Jalon : 6 · Prérequis : T-6.8, réponse G-9 « VAE Core AI : oui » · Tier : 2 (appareil) · ⛔ GATE : non

## Objectif
Le VAE tourne en Core AI sur l'iPhone (placement GPU ou ANE décidé à G-9), assets `.aimodel` compilés à l'avance par Xcode, repli MLX automatique si l'asset est absent ou échoue.

## À lire
- `Sources/YuE2Core/CoreAI/CoreAIVAEDecoder.swift` (le vôtre) ; `plan/13-ios-backend.md` §13.4

## Étapes
1. L'asset `.aimodel` est soit dans *Resources* (compilé à l'avance par Xcode), soit téléchargé avec le pack (T-6.8) puis spécialisé une fois (`AIModel.specialize(contentsOf:)`, avec message « Préparation… ») ; `YuE2Runtime.mobile.vaeBackend` = valeur de G-9.
2. `BenchView` : ligne « VAE : Core AI <ms> / MLX <ms> » ; `SongDetailView` affiche le backend utilisé.
3. Mesure sur l'appareil : décodage d'un clip de 30 s avec chaque backend (temps, énergie approximative via l'état thermique).

## Validation
1. `Scripts/ios-build.sh` → `IOS APP INSTALLED`
2. Sur l'appareil : même clip décodé par les deux backends, SNR > 40 dB (calculé dans l'app, affiché) ; temps consignés

## Critère de fin
Validations vertes ; ligne `BENCHMARKS.md` (section iOS).
