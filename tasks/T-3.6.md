## Objectif

- `reference/yue/src/yue2/cli.py` lignes 86-140

## Fichiers à créer
- `Sources/YuE2Core/Pipeline/YuE2Pipeline.swift` (≤ 200 l.) : `public final class YuE2Pipeline { init(session: ModelSession, vae: YuE2VAE, config: GenerationConfig) ; func generate(request:, abcSampling:, semanticSampling:, onEvent: (PipelineEvent) -> Void, cancel:) throws -> SongResult }` — ordre : `plan` → `generateSemantic` → `synthesize` → `Memory.clearCache()` → `decodeTiled` ; `YuE2MemoryManager.configure` à chaque étape ; timings par étape.
- `Sources/YuE2Core/Pipeline/SongResult.swift` : `audio [1, N, 2]`, `sampleRate 48000`, `semantic`, `latents`, `config` (dictionnaire effectif §`effective_config`), `timing` ; `func save(to wav: URL, format:)` ; `func saveArtifacts(to dir: URL)` : `score.abc`, `abc_tokens.npy`, `prefix.npy`, `plan.json`, `semantic.npy`, `latent.npy`, `audio.wav`, `request.json`, `config.json`, `result.json` (`status`, `truncated`, `sample_rate`, `audio_seconds`, `timing`, `artifacts` = SHA-256 par fichier).
- `Sources/YuE2CLI/GenerateCommand.swift` : options de T-2.10 + `--ode-steps`, `--out`, `--format`, `--profile` (T-3.7) ; `Sources/YuE2CLI/SynthesizeCommand.swift` : `--semantic <dir>` reprend depuis `semantic.npy` + `plan`.
- `Scripts/reference/real_fixtures.py` sous-commande `song` : `YuE2Pipeline.from_pretrained(models_dir/"YuE2-3B", vae=models_dir/"YuE2-Vae", device="mps")` avec `GenerationConfig(abc=Sampling(..., max_tokens=64), semantic=Sampling(..., min_tokens=0, max_tokens=100), ode_steps=4)` sur `song.json` → `save_artifacts(models_dir/"parity/song")`.
- `Tests/YuE2Tests/GenerationSmokeTests.swift` : chanson courte (mêmes réglages) ⇒ `audio.wav` fini, frames == `T·1920 − 64`, RMS ∈ [1e-3, 0.7], `result.json` valide, `truncated.semantic == true` (100 tokens < fin).
