# T-1.10 — Parité real du VAE + `yue2 parity vae`

Jalon : 1 · Prérequis : T-1.9, T-1.4 · Tier : 2 · ⛔ GATE : non

## Objectif
Prouver sur les vrais poids que le décodeur Swift reproduit torch CPU fp32 (40 frames) et que le tuilage 1024 sur 1 100 frames est exact.

## À lire
- `plan/08-tests.md` ligne `vae`
- `reference/h3/Sources/MiniMaxH3CLI/ParityCommand.swift` lignes 1-80 (forme : un `case` par composant, tolérance en option, impression `PARITY …`)

## Fichiers à créer
- `Scripts/reference/real_fixtures.py` (sous-commande `vae` ; les sous-commandes `lm`, `nar`, `song` viendront en T-2.9/T-3.5/T-3.6) : charge `YuE2VAE.from_pretrained(models_dir/"YuE2-Vae", decoder_only=True, device="cpu")`, `latent_40 = randn(1,64,40, seed 11)` → `audio_40 = decode` ; `latent_1100 = randn(1,64,1100, seed 12)` → `audio_1100_full = decode`, `audio_1100_tiled = decode_tiled(core_frames=1024)` ; écrit `$YUE2_MODELS_DIR/parity/vae.safetensors` avec `metadata.kind = "real_vae"`.
- `Sources/YuE2CLI/ParityCommand.swift` : `yue2 parity vae --models-dir <dir> [--tolerance-abs 2e-3] [--tolerance-rel 1e-3]` : charge la fixture, exécute `decode` et `decodeTiled`, imprime `PARITY vae_40: max=<x> rel=<y>`, `PARITY vae_1100_tiled_vs_full: max=…`, `PARITY vae_1100_tiled_vs_torch: max=…`, puis `PARITY OK vae max=<max> rel=<max>` ou `PARITY FAILED vae …` (code de sortie 1).
- `Tests/YuE2Tests/RealVAEParityTests.swift` (tier 2, `.enabled(if:)` sur `YUE2_MODELS_DIR` **et** existence de `parity/vae.safetensors`) : mêmes comparaisons.
- `Tests/YuE2Tests/TestUtilities/ParityHelpers.swift` : `relativeError(a,b) = mean|a−b| / mean|b|`, `maxAbs(a,b)`, `loadFixture(name:) -> [String: MLXArray]`, `modelsDir()`.

## Étapes
1. `.venv-ref/bin/python Scripts/reference/real_fixtures.py vae --models-dir "$YUE2_MODELS_DIR"` (≈ 1-3 min CPU).
2. CLI + test ; commit `feat(parity): real VAE parity`.

## Validation
1. `Scripts/check-build.sh` → `BUILD OK`
2. `Scripts/check-parity.sh vae` → `PARITY OK vae max=<≤2e-3> rel=<≤1e-3>`
3. `Scripts/check-tests.sh RealVAEParityTests` → `TESTS OK (≥ 2 tests, 0 skippés)`

## Critère de fin
Validations vertes. Si `max` > 2e-3 mais `rel` < 1e-3 : noter les deux valeurs dans le journal et continuer (ordre de grandeur fp32 sur 110 convs) ; si `rel` > 1e-2 : STOP, `tasks/ASK.md` avec le premier tap divergent (relancer la bissection tiny d'abord).
