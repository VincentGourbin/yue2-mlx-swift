# T-6.12 — Réglages appareil : pas d'ODE, tuile VAE, cache KV fp16, pacing thermique

Jalon : 6 · Prérequis : T-6.11 (G-10 : « on règle ») · Tier : 2 (appareil) · ⛔ GATE : non

## Objectif
Trouver les réglages par défaut du profil `mobile` par mesures A/B sur l'appareil, sans dégrader l'écoute.

## Étapes (une mesure = une ligne de `BENCHMARKS.md`, section iOS)
1. ODE 32 vs 24 vs 16 pas : temps NAR, SNR entre latents (32 = référence), écoute des trois (question ASK).
2. Tuile VAE 256 vs 512 frames : temps, pic mémoire.
3. Cache KV en fp16 (déjà le cas si `precision fp16`) vs bf16 : mémoire, tok/s.
4. Pacing thermique : seuil `.serious` vs `.critical`, durée de pause ; temps total et température finale.
5. Fixer `YuE2Runtime.mobile` ; commit `perf(ios): default mobile runtime settings`.

## Validation
1. `Scripts/check-tests.sh` → `TESTS OK (…)` ; `Scripts/check-build-ios.sh` → `BUILD IOS OK`
2. Tableau A/B complet dans `BENCHMARKS.md` ; réglages par défaut justifiés dans `docs/knowledge/log.md`

## Critère de fin
Validations vertes ; réglages figés et écoutés.
