# T-1.6 — Lecture/écriture `.npy` et export WAV

Jalon : 1 · Prérequis : T-1.0 · Tier : 1 · ⛔ GATE : non

## Objectif
Lire/écrire les artefacts numériques (`semantic.npy` int32 1-D, `latent.npy` float32 [T,64]) et écrire un WAV stéréo 48 kHz (int16 et float32).

## À lire
- `reference/ltx/Sources/LTXVideo/Utils/AudioExporter.swift` (102 lignes, à copier)
- Format npy v1.0 : en-tête `\x93NUMPY`, version (1,0), longueur d'en-tête uint16 LE, dictionnaire ASCII `{'descr': '<i4'|'<f4', 'fortran_order': False, 'shape': (n,) ou (T, 64), }` complété d'espaces jusqu'à un multiple de 64 octets (avec le `\n` final), puis données little-endian.

## Fichiers à créer
- `Sources/YuE2Core/Audio/NumpyIO.swift` : `public enum NumpyIO { static func readInt32(url) throws -> [Int32]; static func readFloat32(url) throws -> (shape: [Int], data: [Float]); static func writeInt32(_:[Int32], url); static func writeFloat32(_:[Float], shape:[Int], url) }` ; MLX : `static func readArray(url) throws -> MLXArray` (float32 → `MLXArray(data, shape)`).
- `Sources/YuE2Core/Audio/AudioExporter.swift` : copie de ltx (`exportToWAV(audio: MLXArray [2,T] ou [B,2,T], url:, sampleRate: 48_000, gain: 1, format: .int16 | .float32)`), clamp [-1, 1], entrelacement L/R, un seul `eval`.
- `Tests/YuE2Tests/NumpyAndWavTests.swift` : round-trip int32 et float32 [7,64] (octets identiques après réécriture) ; WAV int16 de 1 000 échantillons stéréo : taille = 44 + 4 000, relecture via `AVAudioFile` (48 000 Hz, 2 canaux, 1 000 frames) ; WAV float32 : `AVAudioFile` lit `pcmFormatFloat32`.
