# T-6.0 — `YuE2Core` compile pour iOS

Jalon : 6 · Prérequis : T-5.2 · Tier : 1 · ⛔ GATE : non

## Objectif
La bibliothèque et ses dépendances compilent pour `generic/platform=iOS` sans toucher au comportement macOS.

## À lire
- `plan/13-ios-backend.md` §13.4 (architecture) — lire ce fichier une seule fois, il fait 200 lignes : `read` avec `limit 100` puis `offset 100`, puis `offset 200`
- `reference/voxtral/Sources/VoxtralCore/Utils/ModelDownloader.swift` lignes 10-25 (chemin conteneur iOS)
- `reference/voxtral/Package.swift` lignes 1-40 (platforms macOS + iOS)

## Fichiers à modifier
- `Package.swift` : bump `// swift-tools-version:` à `6.4` (requis pour `SupportedPlatform.IOSVersion.v27`, vérifié : `.v27` lève `error: 'v27' is unavailable ... introduced in PackageDescription 6.4` sous 6.0) puis `platforms: [.macOS(.v15), .iOS(.v27)]` — la cible d'iOS de ce Jalon est **iOS 27** (Core AI, `plan/13-ios-backend.md` rev. 2), pas iOS 17 ; la cible `YuE2BenchUI` reste macOS (AppKit) : la marquer `.executableTarget` avec `swiftSettings` inchangés mais ne pas la référencer depuis un build iOS (on ne compile que le schéma `YuE2Core` pour iOS).
- `Sources/YuE2Core/Loading/ModelDownloader.swift`, `ModelCatalog.swift` : `defaultModelsDirectory` = `$YUE2_MODELS_DIR` sur macOS, `Caches/models` du conteneur sur iOS (`#if os(iOS)`).
- Tout `import AppKit`/API macOS dans `YuE2Core` (`grep -rn "AppKit\|NSWorkspace\|Process(" Sources/YuE2Core`) : aujourd'hui aucun ; `AudioImporter` (`AVAudioFile`) et `AudioExporter` sont portables.
- `Sources/YuE2Core/Memory/YuE2MemoryManager.swift` : `static var profile: Profile = .mac` avec `.mobile` (cacheLimit 256 Mo par étape, `GPU.set(memoryLimit:)` à 3 Go), sélection automatique `#if os(iOS)`.

## Étapes
1. Modifier `Package.swift` ; `xcodebuild -scheme YuE2Core -destination 'generic/platform=iOS' -derivedDataPath .xcodebuild build > .local-runs/build-ios.log 2>&1` ; corriger jusqu'à `BUILD SUCCEEDED`.
2. Ajouter `Scripts/check-build-ios.sh` (copie de `check-build.sh` avec la destination iOS et le schéma `YuE2Core`, verdict `BUILD IOS OK`).
3. Suite Mac inchangée ; commit `build: YuE2Core compiles for iOS 27`.

## Validation
1. `Scripts/check-build.sh` → `BUILD OK`
2. `Scripts/check-build-ios.sh` → `BUILD IOS OK`
3. `Scripts/check-tests.sh` → `TESTS OK (128 tests, 0 skippés)`

Validations vertes.
