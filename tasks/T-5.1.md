## Faits d'architecture (vérifiés dans `reference/yue/src/yue2/modeling_vae.py`, lignes 113-152 et 156-198 pour la topologie, 488-513 pour `encode()`)

Config réelle (`config.json`, clé `encoder_config`, jamais lue par `VAEConfig.swift` jusqu'ici) : `in_channels 2`, `channels 64`, `c_mults [1,2,4,8,16,32]`, `strides [2,2,4,4,5,6]` (même produit 1920 que le décodeur), `latent_dim 128` (⚠️ différent du `latent_dim` top-level 64 : l'encodeur sort `mean ‖ scale` concaténés sur l'axe canal), `use_snake true`.

Topologie (`encoder.layers`, indices = clés du checkpoint) — symétrique du décodeur mais **pas un miroir naïf** (ordre résidus/downsample inversé par rapport à `DecoderBlock`, et le kernel/padding de la dernière conv diffère) :

| Index | Module | Détail |
|---|---|---|
| 0 | `WNConv1d(2 → 64, k=7, p=3)` | weight-norm, **avec biais** (pas de `bias=False` dans la référence) |
| 1..6 | `EncoderBlock(in → out, stride)` : (64→128, s2), (128→256, s2), (256→512, s4), (512→1024, s4), (1024→2048, s5), (2048→4096, s6) — **ordre croissant**, pas décroissant comme le décodeur | chaque bloc = 3 × `ResidualUnit(in, dilation 1, 3, 9)` → `SnakeBeta(in)` → `WNConv1d(in→out, k=2·stride, stride=stride, padding=ceil(stride/2))` — **résidus d'abord, downsample ensuite** (inverse de `DecoderBlock`) |
| 7 | `SnakeBeta(4096)` | |
| 8 | `WNConv1d(4096 → 128, k=3, p=1)` | **k=3/p=1**, pas k=7/p=3 comme la dernière conv du décodeur ; **avec biais** |

`ResidualUnit`, `SnakeBeta`, la fusion `weight_norm` (`w = g·v/‖v‖`, norme sur toutes les dims sauf 0) et la conversion de layout Conv1d torch `[out,in,k] → MLX [out,k,in]` sont **déjà portées et testées** (`VAEWeightLoader.mergeWeightNorm`/`conv1dToMLX`, `ResidualUnit.swift`, `SnakeBeta.swift`) — réutiliser tel quel, aucune transposée ici (l'encodeur n'a que des `Conv1d`, jamais de `ConvTranspose1d`).

`encode()` (bottleneck, `modeling_vae.py:488-513`) :
```
pre = encoder(audio)                        # [B, 128, T] torch  ==  [1, T, 128] MLX NLC
mean, scale = pre.chunk(2, dim=1)           # torch dim=1 (canal) == dernier axe en NLC MLX
stdev = softplus(scale) + 1e-4
latent = mean                                # défaut (sample=false) — c'est le seul mode utile ici (T-5.2 encode un vrai fichier, pas d'entraînement)
# sample=true (latent = noise*stdev + mean) : garder l'API mais ne pas l'exposer en CLI en T-5.2, hors périmètre de la demande de Vincent
```
Entrée attendue : audio `[B,2,S]` torch fp32, `S ≥ downsampling_ratio` (1920) ⇒ au moins 1 frame latente. En NLC MLX : `[1, S, 2]`.
