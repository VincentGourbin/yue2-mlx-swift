# T-5.2 — Ingestion audio (MP3/WAV/…) + `yue2 encode` + round-trip réel

Jalon : 5 (hors plan initial) · Prérequis : T-5.1 · Tier : 1 (tests synthétiques) + démo manuelle (fichier réel de Vincent) · ⛔ GATE : non

## Objectif
Lire un fichier audio quelconque (MP3, WAV, M4A…) via `AVFoundation`, le convertir en `[1,S,2]` fp32 48 kHz, l'encoder en latents avec `YuE2VAEEncoder` (T-5.1), et optionnellement le redécoder pour une comparaison à l'oreille (« round-trip »). Fichier de test réel fourni par Vincent (un MP3 personnel, hors dépôt) : ne jamais committer ce fichier ni une fixture qui en dérive — piège n°16.

## Fichiers à créer
- `Sources/YuE2Core/Audio/AudioImporter.swift` (miroir de `AudioExporter.swift`) : `public enum AudioImporter { static func loadAudio(url: URL, sampleRate: Double = 48_000) throws -> MLXArray }`. Implémentation :
  1. `AVAudioFile(forReading: url)` — si l'ouverture échoue, `throw YuE2Error.missingFile(url.path)`.
  2. Format cible : `AVAudioFormat(commonFormat: .pcmFormatFloat32, sampleRate: sampleRate, channels: 2, interleaved: false)`.
  3. `AVAudioConverter(from: file.processingFormat, to: targetFormat)` — gère resampling ET remix mono→stéréo/multicanal→stéréo automatiquement (comportement standard d'`AVAudioConverter`, pas de mixage manuel à écrire).
  4. Lire le fichier source entier dans un `AVAudioPCMBuffer` (`frameCapacity: AVAudioFrameCount(file.length)`, `file.read(into:)`), puis convertir en un buffer de sortie dimensionné généreusement (`ceil(sourceFrameCount * sampleRate / sourceSampleRate) + 4096` de marge) via `converter.convert(to:error:withInputFrom:)` (pattern standard : le bloc d'entrée fournit le buffer source une seule fois puis renvoie `.endOfStream`).
  5. Tronquer le buffer de sortie à `outputBuffer.frameLength` réel (pas la capacité allouée).
  6. Construire l'`MLXArray` `[1, S, 2]` à partir des deux canaux `floatChannelData` (non-interleaved) — écrire un buffer plat `[L0, R0, L1, R1, ...]` ou construire directement via deux `MLXArray` par canal puis `stacked(axis: -1)`, au choix le plus simple à tester.
  7. Rejeter (`YuE2Error.invalidRequest`) un fichier de durée nulle ou dont la conversion échoue.
- `Sources/YuE2CLI/EncodeCommand.swift` : `yue2 encode --audio <path> --out <dir> [--models-dir] [--vae standard|legacy] [--roundtrip] [--format int16|float32]`.
  - Charge `YuE2VAEEncoder.load(directory: modelsDir/vaeChoice.directoryName)` (T-5.1).
  - `audio = AudioImporter.loadAudio(url: audioPath)`.
  - `latent = encoder.encode(audio)` → écrit `<out>/latent.npy` via `NumpyIO.writeFloat32` en forme `[T, 64]` (squeeze du batch — même convention que `SongResult.saveArtifacts`, jamais `[1,T,64]` sur disque).
  - Si `--roundtrip` : charge aussi `YuE2VAE.load(directory:)` (décodeur, T-1.7-T-1.11), `audio_out = vae.decodeTiled(latent)`, exporte `<out>/roundtrip.wav` via `AudioExporter` (même format que `yue2 decode`).
  - Imprime : `encoded <basename>: <S> samples (<duration format="%.1f">s) -> <T> frames latent` puis, si `--roundtrip`, `roundtrip: <out>/roundtrip.wav (<duration>s)`.
- `Tests/YuE2Tests/AudioImporterTests.swift` (tier 1, sans fichier réel) : exporte un WAV float32 synthétique connu via `AudioExporter` (sinusoïde ou bruit seedé, quelques centaines de frames, 48 kHz stéréo), relis-le avec `AudioImporter.loadAudio`, vérifie la forme `[1,S,2]`, les valeurs proches de l'original (tolérance flottante serrée, écriture/lecture float32 doit être quasi exacte) et le compte d'échantillons exact (pas de resampling ici puisque même taux). Test séparé : écrire un WAV à un taux différent (ex. 44100 Hz) et vérifier que `loadAudio(sampleRate: 48_000)` renvoie bien `round(S_in * 48000/44100)` échantillons à ±1. Test d'erreur : fichier inexistant → throws.

## Étapes
1. `AudioImporter` + tests (aucune dépendance sur T-5.1, testable seul). `Scripts/check-build.sh` puis `Scripts/check-tests.sh AudioImporterTests`.
2. `EncodeCommand` (dépend de T-5.1). `Scripts/check-build.sh`.
3. Commit `feat(cli): audio import and yue2 encode`.
4. **Démo manuelle avec le fichier réel de Vincent** (pas une fixture, pas dans la suite de tests) :
   ```
   yue2 encode --audio "<chemin local vers le fichier audio de test>" \
     --out .local-runs/magic-system-roundtrip --roundtrip --models-dir "$YUE2_MODELS_DIR"
   ```
   Écouter `.local-runs/magic-system-roundtrip/roundtrip.wav` contre l'original — c'est un test de qualité perceptuelle (compression audio avec perte, comme tout VAE), pas une parité bit-exacte : un peu de perte de détail est normale et attendue, l'objectif est que la structure musicale (rythme, mélodie, voix) reste clairement reconnaissable.
