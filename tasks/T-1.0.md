## Fichiers à créer
- `Package.swift` : nom `YuE2Swift`, `swift-tools-version: 6.0`, `platforms: [.macOS(.v15)]` ; produits `.library(name: "YuE2Core")`, `.executable(name: "yue2")`, `.executable(name: "yue2-bench-ui")` ; dépendances **exactement** celles de §4.1 (mlx-swift `exact: "0.31.6"`, swift-transformers `from: "1.3.3"`, swift-argument-parser `from: "1.8.2"`, swift-mlx-profiler `from: "1.5.0"`) ; cibles `YuE2Core` (MLX, MLXNN, MLXRandom, MLXFast, Tokenizers, MLXProfiler), `YuE2CLI` (YuE2Core, ArgumentParser, MLXProfiler), `YuE2BenchUI` (YuE2Core), `YuE2Tests` (YuE2Core).
- `Sources/YuE2Core/YuE2Core.swift` : `public enum YuE2 { public static let version = "0.1.0" }`, `public enum YuE2Error: Error, CustomStringConvertible` (cas `invalidRequest(String)`, `missingFile(String)`, `weightMismatch(String)`, `nonFiniteLatents`, `cancelled`), `public enum YuE2Debug { static let enabled = ProcessInfo.processInfo.environment["YUE2_DEBUG"] != nil; public static func log(_ s: @autoclosure () -> String) }`.
- `Sources/YuE2CLI/YuE2CLI.swift` : `@main struct YuE2CLI: AsyncParsableCommand`, `CommandConfiguration(commandName: "yue2", abstract: "YuE2 music generation on Apple Silicon (MLX)", version: YuE2.version, subcommands: [InfoCommand.self], defaultSubcommand: InfoCommand.self)` ; `InfoCommand` imprime la version et `YUE2_MODELS_DIR` (ou « non défini »).
- `Sources/YuE2BenchUI/YuE2BenchUIApp.swift` : app SwiftUI minimale `Text("YuE2 bench — à venir")`.
- `Tests/YuE2Tests/SmokeTests.swift` : `import Testing`, `@Suite("Smoke") struct SmokeTests { @Test func versionIsSet() { #expect(YuE2.version == "0.1.0") } }`.
- `CLAUDE.md` : contenu de l'Annexe B, verbatim.
- `README.md` : 15 lignes (nom, licence code Apache-2.0, poids CC-BY-NC-4.0, commandes de l'Annexe C).

- Vérifier que `.gitignore`, `Scripts/*.sh`, `tasks/*` existent déjà (fournis par le plan) — ne pas les réécrire.

## Étapes
1. `git init` si `.git` absent ; `git add -A && git commit -m "chore: plan and task harness"` (le plan et les scripts).
2. Écrire `Package.swift` puis les fichiers Swift ci-dessus.
3. `Scripts/check-build.sh` ; corriger jusqu'à `BUILD OK`.
4. `Scripts/check-tests.sh SmokeTests` ; attendu `TESTS OK (1 tests…)`.
5. Écrire CLAUDE.md, README.md, docs/knowledge/*.
6. `git add -A && git commit -m "feat: package skeleton (YuE2Core, yue2 CLI, tests)"`.
7. Écrire dans `tasks/ASK.md` la question G-0 : « Plan rév. 1 validé ? Nom du dépôt GitHub ? Valeur de `$YUE2_MODELS_DIR` ? » puis terminer.
